## 知识图谱 tags 字段类型修复（`@skill:understand-chat` 使用中发现）

- 用 `@skill:understand-chat` 查询 mall 业务时，遍历节点触发 `TypeError: (n.tags || []).join is not a function` → 排查发现 **43 个节点的 `tags` 是 JSON 字符串而非数组**（如 `"[\"mall-module\",\"browse\"]"`），全部来自本次增量更新中新分析的批次。
- 已就地修复 `.ua/knowledge-graph.json`：能 `JSON.parse` 成数组的解析为数组，其余按分隔符切分。修复后 1252 节点 / 2260 边 / 15 层 / 14 步导览，`tags` 全部为数组、无空 tags。
- **根因**：SKILL.md 内联的确定性校验器只检查 `!n.tags || !n.tags.length`（字符串非空即通过），**不校验 `Array.isArray`**，所以这类缺陷会静默通过 `issues: 0`。下次跑 `/understand` 后建议补一段 `Array.isArray(tags)` 检查，或直接 `grep -c '\"tags\": \"'` 自查。
- 影响面：只影响展示类字段（tags），不影响节点/边结构、分层、导览。

## 「mall 业务是否完善 / 闭环」评估（08:11）

结论：**主干闭环成立，但闭环止于「报价」**——本质是 RFQ 线索撮合系统，不是交易系统。证据与缺口清单：

- **已闭环（有接口 + 有约束 + 有测试）**：选型浏览（设备↔滤清器适配矩阵）→ 登录（密码/微信）→ 收藏·地址 → 询价创建→提交 → 后台报价（`PATCH /inquiry/inquiry-lines/:id` 填 unitPrice，`PATCH /inquiry/inquiries/:id/status` 置 quoted + 可选 expiresAt，行小计与总额服务端派生）→ 客户 `GET /inquiries/:id` 可见单价/小计/总额/`isExpired`。数据链完整。
- **缺口 P0（结构性断裂）**：① 报价之后无出口——`INQUIRY_STATUS_TRANSITIONS` 里 `quoted → expired` 是唯一后继，且**无接受报价/订单/支付/物流模型**（schema 无 Order/Payment/Shipment）。② **全链路零通知**：无 mail/SMS/微信模板消息（`Notice`/`UserNoticeRead` 是后台 User 内部公告，与 Customer 无关）→ 客户提交、后台报价、报价过期三处状态变更**都没有任何一方被通知**，闭环依赖用户主动回访。
- **缺口 P1**：③ 草稿不可改——`CreateCustomerInquiryDto` 强制一次给齐 1–50 条明细（`ArrayMinSize(1)`），且客户侧**无** lines/标题/地址的 PATCH 端点 → draft 只能取消重建，不是"询价车"。④ 客户自助面窄（无注册/改密/找回密码/资料维护，重置密码唯一路径是 admin `PATCH /customer/customers/:id`）。⑤ 微信契约仅 openid，unionid 待接入。⑥ 可用性门控 TTL 内不校验（`CUSTOMER_AVAILABILITY_CHECKED_WITHIN_TTL = false`，ADR 0011 决策 3）→ 封禁最长延迟一个 access TTL（有意的权衡）。
- **缺口 P2**：⑦ 报价无版本、`expiresAt` 选填（不填=永久报价）。⑧ 过期只是派生展示态（`isInquiryExpired`），**全仓无调度能力**（无 `ScheduleModule`/`@Cron`/`setInterval`）→ DB 状态不会自动流转，靠后台人工置 expired。
- 若补闭环：最短路径是**微信订阅消息**（openid 已在手）+ unionid；若要做交易，则需新 capability 承载报价单/接受/订单/履约，当前 schema 无任何承载。

## OpenAPI 契约导出能力（08:17）

- **新增** `scripts/export-openapi.ts` + `pnpm openapi:export`：拉取运行实例的 `/api-json` 与 `/api-yaml`，写 `openapi/<app>.json|yaml`。支持 `--admin/--mall <url>`、`ADMIN_API_URL/MALL_API_URL`、`--out`、`--docs-path`；任一应用取不到契约即非零退出；含契约自检（缺 `openapi`/`info.title`/`paths` 判定为非法文档，防止把错误页落盘误导前端）。

- 挂载路径：`SwaggerModule.setup('api', ...)` → UI `/api`、JSON `/api-json`、YAML `/api-yaml`。**Swagger 未按 NODE_ENV 关闭，生产同样暴露**（安全项，若要收敛需另开变更）。

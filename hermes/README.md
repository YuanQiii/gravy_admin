# Hermes — Query Persistent Memory

本目录是 GVRAY 工程的**持久化经验库**（踩坑 / 决策 / 工程模式），供人机共同引用。与 `docs/`（面向契约与规范的正式文档）互补：Hermes 侧重**沉淀下来的经验与不变量**，文档侧侧重**当前形态与规程**。两者冲突时以源代码为准（见 AGENTS.md 硬规则）。

> 命名：Hermes 是信使之神——这里存放让后续工作不再"重新踩坑"的信使型内容。

## 维护约定

- **来源**：主要来自已归档 OpenSpec 变更（`openspec/changes/archive/`）与 [docs/adr/](../docs/adr/)。新增变更归档后，把其中"值得记住"的踩坑/决策/模式回填到这里。

- **链接优先**：优先指向源码、ADR、变更文档的绝对/可点路径，不复制大段实现。

- **语言**：中文为主（与仓库中文规范一致），保留英文专有名词/技术术语。

- **收敛**：一条经验只写一处；发现重复先合并。

- **不写**：可直接从 `AGENTS.md` / ADR / spec 读到的当前状态描述，只记「为什么 / 别踩 / 教训」。
